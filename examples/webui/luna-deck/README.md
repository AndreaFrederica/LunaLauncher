# Luna Deck

浅色、深绿侧栏和橙色强调的独立静态测试 UI。没有构建依赖，复制整个目录到宿主
旁边的 `webui/luna-deck`，在 Web UI 管理器选择 **Luna Deck · 浅色测试界面**。

它使用真实实例列表、图标、账户、启动和控制台 API，可直接运行 Minecraft：

1. 在实例库选择已有账户（默认遵循实例绑定 / 启动器默认账户）。Microsoft、离线、
   Yggdrasil 和统一通行证账户均交给后端处理；需要重新认证时会显示输入或浏览器授权弹窗。
2. 点击实例卡片的“启动 Minecraft”。准备阶段显示任务状态，可以取消可中断的启动任务；
   失败原因会留在控制台，不会一直显示“正在启动”。
3. 游戏启动后显示进程 PID 和实时日志。可回实例库启动其他实例，通过“运行与日志”
   下拉框切换各实例输出；停止客户端前有确认提示。

离线模式使用已下载游戏文件，也可以填写临时离线玩家名，不修改保存的账户。
每个实例保留最近 2,000 条输出，支持跟随和手动滚动；已经运行的实例也能重新订阅。
这是客户端启动示例，不是服务端终端。实例编辑、新增账户和下载管理仍在完整 Neo UI。

左侧“界面加载设置”直接
通过 `luna.webUiSettings()` / `luna.updateWebUiSettings()` 编辑宿主设置，也可以在
页面内切换到其他 UI，运行的游戏可继续运行。

需要包含加载设置 API 的新版宿主。普通浏览器可预览布局，但无法连接真实数据。
源码及自绘图形遵循 GPL-3.0-only；详细协议见 [Web UI 开发文档](../../../docs/WEBUI-DEVELOPMENT.md)。

开发验证：`pixi run python tests/deck_launch_smoke.py --exe install-neo-ui-api/luna-neo-ui.exe`
在隔离目录中通过真实宿主点击按钮，检查账户弹窗和认证取消。添加
`--cache-root <已有启动器数据目录> --java <Java 21 的绝对路径>` 可用已缓存的
Minecraft 1.21.8 验证真实启动、日志、实例控制台切换和停止；只复制游戏缓存，不复制账户或存档。
