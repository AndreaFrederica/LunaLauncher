Web UI manager

Place compiled static files in a separate folder under webui, with index.html as the entry point. An optional webui.json can describe the name and version.

Switching reloads the page and loses unsaved interface input. Running clients continue; finish the current download or login first.

Interface loading settings

Saving settings does not switch the current page. Startup options take effect the next time the launcher opens.

Scan directories

Press Ctrl / ⌘ + Shift + U to open this window at any time. Use only Web UIs you trust; they can call the launcher API.
