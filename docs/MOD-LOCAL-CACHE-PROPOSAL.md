# Mod 本地内容缓存设计提案

> 状态：待审阅，尚未实现。本文描述目标架构和迁移步骤，不代表当前版本已经启用 Mod 去重缓存。

## 目标

同一个 Mod 文件只下载一份，多个实例通过硬链接、符号链接或复制复用该文件。缓存应覆盖普通下载、手动选择文件，以及 CurseForge 受限文件经过 WebView 下载后的导入流程。

缓存的权威身份是文件内容，而不是下载 URL。URL、项目 ID、版本 ID 和文件名只用于展示、查找和诊断。

## 内容键和目录

优先使用 provider 给出的文件哈希及算法，例如 SHA-1 或 SHA-256。缓存键应同时包含算法和规范化后的十六进制哈希，避免不同算法的值发生碰撞：

```text
<dataRoot>/cache/mods/<algorithm>/<hash>/<safe-file-name>
```

建议同时保存一份侧车元数据（例如 `meta.json`），记录文件大小、来源 provider、项目/版本/文件 ID、原始 URL、导入时间和最近使用时间。文件名只保留 basename，并过滤路径分隔符、`.`、`..` 和控制字符，防止路径穿越。

没有 provider 哈希时，可以用 URL、文件名和大小组成临时候选键，但候选命中必须重新计算内容哈希；无法完成校验时不能把文件当作可信缓存，也不能覆盖已有哈希对象。

## 下载和复用流程

1. 读取下载元数据，先按算法和哈希查找缓存。
2. 命中后检查文件存在、大小匹配，并重新计算哈希；校验通过才复用。
3. 将未命中的内容下载到缓存目录之外的临时文件，例如 `.part/<random-id>.part`。
4. 下载完成后校验哈希。校验失败删除临时文件并返回错误，不得写入正式缓存。
5. 通过同目录临时名称加原子 rename 写入最终缓存，避免其他任务看到半文件。
6. 将缓存对象挂载到实例的 `mods/` 目录。优先硬链接，失败后按平台策略尝试符号链接，最后复制。
7. 将实际安装方式和最终路径写入任务日志，方便排查跨卷、权限和链接失败。

缓存对象应使用不可变内容模型：同一个哈希不能被覆盖。文件名变化只影响链接名，不影响内容对象。

## 链接策略

- Windows：优先硬链接；目标和实例位于不同卷、权限不足或文件系统不支持时回退到复制。符号链接需要额外权限，默认不依赖它。
- Linux/macOS：优先硬链接或符号链接，仍保留复制回退。跨文件系统时硬链接必然失败。
- 复制回退必须保持校验结果，并在实例文件写入完成后再报告安装成功。
- 删除实例中的链接只能删除链接本身，不能删除缓存目标。若使用复制，需要按哈希登记实例引用，避免清理任务误删仍在使用的副本。

## 并发、失败和恢复

同一个哈希只能有一个写入者。建议以算法和哈希为锁键，锁文件或进程内锁均可：

- 第一个任务负责下载和校验；其他任务等待完成后重新检查缓存。
- 锁拥有者异常退出时，遗留 `.part` 文件可以按时间清理；正式文件必须通过哈希再次验证。
- 目标文件已经存在但校验失败时，移入隔离区或删除后重新下载，不能直接覆盖正在被读取的文件。
- 下载取消、网络错误、校验错误和链接失败都要区分记录，便于 UI 展示和重试。

## 清理和统计

缓存需要大小上限、按最近使用时间（LRU）清理和手动清理入口。清理前应检查引用表；仍被实例使用的对象只能在解除引用后删除。元数据损坏时可以扫描目录重建索引，扫描结果仍须重新校验哈希。

建议提供总对象数、总大小、命中率、复制回退次数和当前锁等待数，便于判断缓存是否有效。

## CurseForge 受限文件

WebView 下载器只负责得到一个本地文件，不能绕过缓存层。下载完成后应走同样的“临时文件 → 哈希校验 → 原子入缓存 → 安装链接”流程。用户在 WebView 中手动选取本地文件时，也应先导入并校验缓存，再安装到实例，避免同一文件因来源不同产生重复副本。

## 兼容和迁移

现有实例中的 Mod 不必立即移动。新下载先使用缓存；后续可以提供“扫描并导入缓存”工具，按内容哈希去重，再把实例文件替换为链接或复制回退。卸载、更新和整合包操作必须继续以实例目录中的文件为入口，不应要求用户理解缓存目录。

## 分阶段实现

1. **第一阶段：可用性**：哈希缓存、完整性校验、临时文件、复制回退；不改变现有 UI 入口。
2. **第二阶段：节省磁盘**：增加硬链接/符号链接，记录链接类型和失败原因。
3. **第三阶段：可靠性**：跨进程锁、引用登记、崩溃恢复、LRU 和大小上限。
4. **第四阶段：可见性**：缓存统计、手动清理、导入现有 Mod、实例级缓存诊断。

实现前需要确定默认哈希算法、缓存目录迁移策略、符号链接权限策略，以及“复制回退”是否计入去重统计。
