# Meson Pattern Snippets

Runnable examples live in each owning skill's `examples/` directory. The patterns described in this cookbook's `SKILL.md` are self-contained snippets meant to illustrate a single concept; they are not standalone projects and do not live here.

To find a runnable example for a specific topic, look in the `examples/` subdirectory of the skill that owns it:

| Pattern | Owning skill | Example path |
|---------|-------------|--------------|
| Reusable library with pkg-config | `meson-advanced-project-design` | `examples/reusable-library/` |
| Executable with tests | `meson-testing-installation` | `examples/executable-with-tests/` |
| Mixed C and C++ | `meson-advanced-project-design` | `examples/mixed-c-cpp/` |
| Generated sources | `meson-advanced-project-design` | `examples/generated-sources/` |
| Plugin system | `meson-advanced-project-design` | `examples/plugin-system/` |
| Wrap fallback dependency | `meson-subprojects-management` | `examples/wrap-fallback/` |
| Cross-compilation | `meson-cross-compilation` | `examples/cross-compilation/` |
| Package installation and staging | `meson-package-export-distribution` | `examples/package-installation/` |
| pkg-config export | `meson-package-export-distribution` | `examples/pkg-config-export/` |
| Named target selection | `meson-compile-targets` | `examples/basic-build/` |
| GitHub Actions CI | `meson-ci-cd-integration` | `examples/github-actions/` |
